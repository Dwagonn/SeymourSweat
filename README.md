this project is made to make your life easyer with sorting the seymour armor pieces in Hypixel Skyblock ,

to use it you have to use the mod iTEM to scan your armor pieces and it will put in ur clipboard some text , then create the file message.txt and paste the text in it.
Then execute the python script if u have download the requirements (ezods and colormath) it will output a .ods file that you can launch if u have LibreOffice installed.
Then go in tools , macro , edit macro and paste the macro and save (CTRL+ S).
And finally you cango in tools , macro then execute macro and select the one you made.
